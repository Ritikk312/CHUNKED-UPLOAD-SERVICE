Resumable Chunked Upload Service
OJT College Project (PST_AD_149)

This service allows large file uploads over unreliable connections by splitting files into 2 MB chunks, retrying failed chunks with exponential backoff, and verifying final file integrity via SHA-256.

Team Roles:
  • Ritik Saini (Backend): Flask server, UploadSession storage, chunk merge in order, whole-file SHA-256 check, admin endpoints, pytest test suite.
  • Kanish (Frontend): uploader.js, hash.js, store.js, Bootstrap 5 UI, chunk map, test lab, and resume integration.
Key Design Concepts:
  • Idempotency: Resending the same chunk safely overwrites without duplication.
  • Sequential Chunking: Uploads chunk-by-chunk to reduce memory and connection overhead.
  • Local State vs Server Truth: localStorage remembers sessions, but the server is the ultimate source of truth for received chunks.
